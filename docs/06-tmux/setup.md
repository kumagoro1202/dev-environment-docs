# tmux 設定

## 確認コマンドと実際の値

```bash
$ tmux -V
tmux 3.4
```

## バニラ状態との差分

### 1. ~/.tmux.conf

**バニラ状態**: ~/.tmux.conf なし（デフォルト設定）

**カスタマイズ後**:
```bash
# マウススクロール有効化
set -g mouse on
```

**効果**: マウスホイールでペイン内をスクロール可能になる。Claude Code の長い出力を確認しやすい。

### 2. マルチエージェント用セッション構成

マルチエージェントAIシステム用に2つの常駐tmuxセッションを使用:

| セッション名 | 用途 | 接続方法 |
|------------|------|---------|
| `shogun` | 将軍（指揮）セッション | `css`（エイリアス）|
| `multiagent` | 足軽・家老 並列実行セッション | `csm`（エイリアス）|

**multiagent セッションのペイン構成例**:
```
┌─────────────────┬─────────────────┐
│ karo (0.0)      │ ashigaru1 (0.1) │
├─────────────────┼─────────────────┤
│ ashigaru2 (0.2) │ ashigaru3 (0.3) │
├─────────────────┼─────────────────┤
│ ashigaru4 (0.4) │ ashigaru5 (0.5) │
├─────────────────┼─────────────────┤
│ ashigaru6 (0.6) │ ashigaru7 (0.7) │
└─────────────────┴─────────────────┘
```

## 再現手順

```bash
# tmux インストール（Ubuntu標準パッケージ）
sudo apt install tmux -y

# .tmux.conf 作成
cat > ~/.tmux.conf << 'EOF'
# マウススクロール有効化
set -g mouse on
EOF

# 設定反映（既存セッションに適用）
tmux source ~/.tmux.conf
```

## 便利なキーバインド（バニラ tmux）

| 操作 | キー |
|------|------|
| プレフィックス | Ctrl+b |
| 新規ウィンドウ | Ctrl+b c |
| 縦分割 | Ctrl+b % |
| 横分割 | Ctrl+b " |
| ペイン移動 | Ctrl+b ←↑→↓ |
| セッション一覧 | Ctrl+b s |
| デタッチ | Ctrl+b d |

## 注意事項

- tmux セッションは WSL2 再起動では消えるが、Windows を再起動しない限り継続する
- マウス有効化後、テキストコピーは Shift+クリックで行う（通常のクリックはペイン選択になる）
