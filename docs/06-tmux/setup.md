# tmux 設定

## 確認コマンドと実際の値

```bash
$ tmux -V
tmux 3.4
```

## バニラ状態との差分

### 1. ~/.tmux.conf

**バニラ状態**: ~/.tmux.conf なし（デフォルト設定）

**カスタマイズ後**:
```bash
# マウススクロール有効化
set -g mouse on
```

**効果**: マウスホイールでペイン内をスクロール可能になる。Claude Code の長い出力を確認しやすい。

### 2. マルチエージェント用セッション構成

マルチエージェントAIシステム用に2つの常駐tmuxセッションを使用
（指揮用セッション名・各ペインのエージェントIDは公開用に一般名称へ置換して記載）:

| セッション名 | 用途 | 接続方法 |
|------------|------|---------|
| `<main-session>` | 指揮エージェント用セッション | `css`（エイリアス）|
| `multiagent` | 管理・作業エージェント並列実行セッション | `csm`（エイリアス）|

**multiagent セッションのペイン構成例**（管理1 + 作業7 の8ペイン）:
```
┌─────────────────┬─────────────────┐
│ manager (0.0)   │ worker-a (0.1)  │
├─────────────────┼─────────────────┤
│ worker-b (0.2)  │ worker-c (0.3)  │
├─────────────────┼─────────────────┤
│ worker-d (0.4)  │ worker-e (0.5)  │
├─────────────────┼─────────────────┤
│ worker-f (0.6)  │ worker-g (0.7)  │
└─────────────────┴─────────────────┘
```

## 再現手順

```bash
# tmux インストール（Ubuntu標準パッケージ）
sudo apt install tmux -y

# .tmux.conf 作成
cat > ~/.tmux.conf << 'EOF'
# マウススクロール有効化
set -g mouse on
EOF

# 設定反映（既存セッションに適用）
tmux source ~/.tmux.conf
```

## 便利なキーバインド（バニラ tmux）

| 操作 | キー |
|------|------|
| プレフィックス | Ctrl+b |
| 新規ウィンドウ | Ctrl+b c |
| 縦分割 | Ctrl+b % |
| 横分割 | Ctrl+b " |
| ペイン移動 | Ctrl+b ←↑→↓ |
| セッション一覧 | Ctrl+b s |
| デタッチ | Ctrl+b d |

## 注意事項

- tmux セッションは WSL2 再起動では消えるが、Windows を再起動しない限り継続する
- マウス有効化後、テキストコピーは Shift+クリックで行う（通常のクリックはペイン選択になる）
